Model OpenAI kini hadir di Google Cloud

GPT-6 Astra, GPT-6.1 Sol, dan GPT-6 Luna mulai digulirkan dalam private preview di model garden Google Cloud, dengan penagihan lewat Google Cloud Marketplace. Apa yang diumumkan, apa yang masih menyusul, dan kenapa ini penting.

22 Okt 2026  •  4 menit baca

Poin penting

  • Google Cloud mengumumkan pada 21 Oktober 2026 bahwa GPT-6 Astra, GPT-6.1 Sol, dan GPT-6 Luna dari OpenAI mulai digulirkan dalam private preview di model garden-nya.
  • Google Cloud mengklaim kini menjadi satu-satunya hyperscaler yang menawarkan Gemini, Claude, dan GPT berdampingan, plus lebih dari 200 model lain.
  • Penagihan lewat Google Cloud Marketplace dan dihitung ke dalam komitmen belanja pelanggan; OpenAI menyebut general availability menyusul dalam beberapa minggu ke depan, dengan Microsoft tetap sebagai mitra cloud utama.
  • Bagi pembeli, ini adalah rute cloud ketiga menuju GPT-6 setelah Microsoft dan AWS — pembedanya adalah Gemini yang ada di platform yang sama.

Apa yang terjadi

Google Cloud mengumumkan pada 21 Oktober 2026 bahwa model-model OpenAI hadir di model garden-nya. Tiga model mulai digulirkan sekarang dalam private preview untuk pelanggan enterprise terpilih: GPT-6 Astra untuk coding berat, computer use, dan riset; GPT-6.1 Sol yang diklaim mendekati kecerdasan Astra dengan biaya lebih rendah untuk agentic coding dan otomasi; serta GPT-6 Luna, model yang cepat dan hemat untuk pekerjaan sehari-hari dalam skala besar.

Pengumuman ini ditulis oleh Michael Gerstenhaber, vice president produk Gemini di Google Cloud. Argumen intinya: AI enterprise adalah soal mencocokkan setiap beban kerja dengan model yang tepat, bukan memakai satu model untuk semuanya.

Satu tagihan, tiga keluarga model

Nilai jualnya adalah pengadaan, bukan kapabilitas. Model-model ini ditagih langsung lewat Google Cloud Marketplace, dan menurut Google, konsumsinya dihitung ke dalam komitmen belanja pelanggan serta Flexible Savings Plans. Tim bisa memanggil model lewat API Google Cloud dan menghubungkan alur kerja Codex CLI dan desktop lokal ke platform untuk inferensi.

Klaim utama Google Cloud: kini mereka menjadi satu-satunya penyedia cloud hyperscale yang menempatkan Gemini, Claude, dan GPT dalam satu platform, bersama lebih dari 200 model pihak pertama, ketiga, dan terbuka. Yang masih menyusul menurut pengumuman: model OpenAI di dalam Gemini for business dan Google Antigravity, tool coding mereka.

Artinya buat kamu

Konteksnya penting. Ini adalah cloud besar ketiga yang menjual GPT-6, bukan yang pertama: Foundry milik Microsoft mencantumkan GPT-6 Astra sebagai generally available pada 3 September 2026, dan Amazon Bedrock menyusul pada 8 September. Postingan OpenAI sendiri menambahkan dua fakta yang perlu diketahui pembeli: general availability di Google Cloud direncanakan dalam beberapa minggu ke depan, dan Microsoft tetap menjadi mitra cloud utama OpenAI.

Jadi beritanya bukan bahwa GPT-6 ada di tempat baru. Melainkan apa yang didapat pelanggan Google Cloud secara spesifik: tanpa kontrak vendor baru, tanpa tagihan terpisah, dan satu hal yang tidak ditawarkan Microsoft maupun AWS — Gemini yang duduk di rak yang sama. Kalau timmu sudah belanja di Google Cloud, meminta akses preview kini menjadi keputusan pengadaan, bukan keputusan arsitektur.

Yang masih belum jelas: Google belum mempublikasikan harganya sendiri untuk model-model ini, jadi jangan anggap sama dengan harga list API OpenAI sebelum tim account-mu mengonfirmasi. Opsi Zero Data Retention dan Confidential Compute juga masih berstatus segera hadir, bukan tersedia hari ini.
